# 用户类型区分机制说明

## 用户类型定义

系统中有4种用户类型：

1. **未登录的游客** - 没有token，未登录
2. **登录的游客** - 有token，但userType为"guest"，未关联项目
3. **登录并关联账户的客户** - 有token，userType为"customer"，有关联项目
4. **登录并关联账户的员工** - 有token，userType为"staff"，有关联项目

## 前端区分机制

### 1. 核心判断文件

#### 文件：`uni3/src/config/guest.js`

**判断函数：`isGuestUser()`**

```javascript
/**
 * 判断当前用户是否为游客（包括未登录用户）
 * @returns {boolean}
 */
export const isGuestUser = () => {
  try {
    // 检查是否已登录
    const token = uni.getStorageSync('token')
    const isLoggedIn = !!(token && token !== '' && token !== 'null')
    
    // 未登录用户视为游客
    if (!isLoggedIn) {
      return true  // ← 未登录的游客
    }
    
    // 检查是否是未登录游客模式
    const guestMode = uni.getStorageSync('guestMode') === true
    
    // 检查是否是已登录的游客用户
    const userType = uni.getStorageSync('userType')
    const isGuestType = userType === 'guest'  // ← 登录的游客
    
    return guestMode || isGuestType
  } catch (error) {
    console.error('[Guest Config] 判断游客状态失败:', error)
    return true // 出错时默认为游客
  }
}
```

**区分逻辑：**
- `!isLoggedIn` → **未登录的游客**
- `isLoggedIn && userType === 'guest'` → **登录的游客**
- `isLoggedIn && userType === 'customer'` → **客户**
- `isLoggedIn && userType === 'staff'` → **员工**

### 2. 页面中的使用

#### 文件：`uni3/src/pages/log/index.vue`

```javascript
import { getCurrentProjectId, isGuestUser } from '@/config/guest'
import { useUserStore } from '@/store/user.js'

const userStore = useUserStore()

// 初始化项目ID
const initProjectId = async () => {
  const projectId = await getCurrentProjectId(urlProjectId.value, userStore.currentProjectId)
  currentProjectId.value = projectId
  
  if (projectId) {
    uni.setStorageSync('currentProjectId', projectId)
    console.log('[Log] 初始化项目ID:', projectId, '是否游客:', isGuestUser())
  }
}

// 当前项目信息
const currentProject = computed(() => {
  if (!currentProjectId.value) return null
  
  // 如果是游客用户（包括未登录），返回演示项目信息
  if (isGuestUser()) {
    return { id: currentProjectId.value, name: '演示项目' }
  }
  
  // 从store的项目列表中查找
  const project = userStore.projects.find(p => p.id === currentProjectId.value)
  if (project) {
    return project
  }
  return { id: currentProjectId.value, name: '当前项目' }
})

// 加载数据
const loadSchedules = async () => {
  if (!currentProjectId.value) {
    console.log('[Log] 没有项目ID，无法加载进度列表')
    if (userStore.isStaff && !isGuestUser()) {
      uni.showToast({
        title: '请先选择项目',
        icon: 'none'
      })
    }
    schedules.value = []
    return
  }
  
  // 调用API加载数据
  const data = await getProjectScheduleList()
  schedules.value = data
}
```

**区分体现：**
- `isGuestUser()` → 判断是否为游客（未登录或登录的游客）
- `userStore.isStaff` → 判断是否为员工
- `userStore.isCustomer` → 判断是否为客户
- `userStore.projects` → 关联的项目列表

### 3. 请求拦截器

#### 文件：`uni3/src/utils/request.js`

```javascript
const requestInterceptor = (config) => {
  // 获取 token
  const token = uni.getStorageSync('token')
  if (token && token !== '' && token !== 'null') {
    config.header = {
      ...config.header,
      'Authorization': `Bearer ${token}`
    }
  } else {
    // 未登录时，不添加Authorization头，但仍然允许请求
    console.log('[Request] 未登录用户，不添加Authorization头')
  }
  
  // 添加当前项目ID
  const currentProjectId = uni.getStorageSync('currentProjectId')
  if (currentProjectId) {
    if (isValidProjectId(currentProjectId)) {
      config.header['X-Project-Id'] = currentProjectId
    }
  }
  
  return config
}
```

**区分体现：**
- 有token → 添加`Authorization`头（登录的游客/客户/员工）
- 无token → 不添加`Authorization`头（未登录的游客）
- 有projectId → 添加`X-Project-Id`头（所有用户）

### 2. 权限验证

#### 文件：`sb3/evs-home/src/main/java/com/ruoyi/app/service/impl/AppProjectScheduleServiceImpl.java`

```java
private void validateTokenAndAccess(String token, String projectId) {
    // 验证项目ID格式
    if (!isValidProjectId(projectId)) {
        throw new ServiceException("无权访问该项目");
    }
    
    // 1. 未登录的游客
    if (token == null || token.isEmpty() || "null".equals(token)) {
        boolean isDemo = guestConfigService.isGuestDemoProject(projectId);
        if (!isDemo) {
            log.warn("[权限验证] 未登录用户尝试访问项目: {}", projectId);
            throw new ServiceException("无权访问该项目");
        }
        log.info("[权限验证] 未登录用户访问演示项目: {}", projectId);
        return;  // ← 未登录的游客，只能访问演示项目
    }
    
    // 2. 尝试验证token
    Map<String, Object> claims = null;
    try {
        claims = tokenManager.validateToken(extractToken(token));
    } catch (Exception e) {
        // Token验证失败
        log.warn("[权限验证] Token验证失败: {}, projectId: {}", e.getMessage(), projectId);
        
        // 如果是演示项目，允许访问（降级为未登录访问）
        boolean isDemo = guestConfigService.isGuestDemoProject(projectId);
        if (isDemo) {
            log.info("[安全审计] 降级访问演示项目: projectId={}, tokenError={}", projectId, e.getMessage());
            return;  // ← 登录的游客（token无效），降级访问演示项目
        }
        
        throw new ServiceException("无权访问该项目");
    }
    
    String userType = (String) claims.get("userType");
    String userId = claims.get("userId").toString();

    // 3. 登录的游客（token有效）
    if ("guest".equals(userType)) {
        boolean hasAccess = guestConfigService.validateGuestProjectAccess(projectId);
        if (!hasAccess) {
            log.warn("[权限验证] 游客用户 {} 尝试访问项目: {}", userId, projectId);
            throw new ServiceException("无权访问该项目");
        }
        log.info("[权限验证] 游客用户 {} 访问演示项目: {}", userId, projectId);
        return;  // ← 登录的游客，只能访问演示项目
    }

    // 4. 客户
    if ("customer".equals(userType)) {
        Projects project = projectMapper.selectProjectById(projectId);
        if (project == null || !userId.equals(project.getCustomerId())) {
            throw new ServiceException("无权访问该项目");
        }
        // ← 客户，只能访问自己的项目
    } 
    // 5. 员工
    else if ("staff".equals(userType)) {
        boolean hasAccess = dashboardMapper.checkStaffProjectAccess(userId, projectId);
        if (!hasAccess) {
            throw new ServiceException("无权访问该项目");
        }
        // ← 员工，只能访问有权限的项目
    }
}
```

**区分逻辑：**

1. **未登录的游客**
   - 条件：`token == null || token.isEmpty() || "null".equals(token)`
   - 权限：只能访问演示项目
   - 验证：`guestConfigService.isGuestDemoProject(projectId)`

2. **登录的游客（token无效）**
   - 条件：`token != null && tokenManager.validateToken() 抛出异常`
   - 权限：只能访问演示项目（降级访问）
   - 验证：`guestConfigService.isGuestDemoProject(projectId)`

3. **登录的游客（token有效）**
   - 条件：`token有效 && userType == "guest"`
   - 权限：只能访问演示项目
   - 验证：`guestConfigService.validateGuestProjectAccess(projectId)`

4. **客户**
   - 条件：`token有效 && userType == "customer"`
   - 权限：只能访问自己的项目
   - 验证：`project.getCustomerId().equals(userId)`

5. **员工**
   - 条件：`token有效 && userType == "staff"`
   - 权限：只能访问有权限的项目
   - 验证：`dashboardMapper.checkStaffProjectAccess(userId, projectId)`

### 3. 游客配置服务

#### 文件：`sb3/evs-home/src/main/java/com/ruoyi/app/service/impl/GuestConfigServiceImpl.java`

```java
@Service
public class GuestConfigServiceImpl implements IGuestConfigService {
    
    private static final String GUEST_DEMO_DICT_TYPE = "guest_demo";
    
    /**
     * 获取游客演示项目ID列表
     */
    @Override
    public List<String> getGuestDemoProjectIds() {
        List<SysDictData> dictDataList = DictUtils.getDictCache(GUEST_DEMO_DICT_TYPE);
        
        if (dictDataList == null || dictDataList.isEmpty()) {
            return new ArrayList<>();
        }
        
        // 提取所有以 projects_ 开头的字典项的值
        List<String> projectIds = dictDataList.stream()
                .filter(dict -> dict.getDictLabel() != null && dict.getDictLabel().startsWith("projects_"))
                .map(SysDictData::getDictValue)
                .filter(StringUtils::isNotEmpty)
                .collect(Collectors.toList());
        
        return projectIds;
    }
    
    /**
     * 检查项目是否为演示项目
     */
    @Override
    public boolean isGuestDemoProject(String projectId) {
        if (StringUtils.isEmpty(projectId)) {
            return false;
        }
        
        List<String> demoProjectIds = getGuestDemoProjectIds();
        return demoProjectIds.contains(projectId);
    }
    
    /**
     * 验证游客是否有权限访问项目
     */
    @Override
    public boolean validateGuestProjectAccess(String projectId) {
        return isGuestDemoProject(projectId);
    }
}
```

**作用：**
- 管理演示项目ID列表
- 验证项目是否为演示项目
- 为游客提供权限验证

```
用户登录
    ↓
后端验证
    ↓
生成Token（包含userType、userId、projectIds）
    ↓
返回给前端
    ↓
前端保存到storage
    ├─ token
    ├─ userType
    ├─ userId
    ├─ userInfo
    └─ projects
```

```
前端发起请求
    ↓
request.js拦截器
    ├─ 添加Authorization: Bearer {token}
    └─ 添加X-Project-Id: {projectId}
    ↓
后端接收请求
    ↓
validateTokenAndAccess()
    ├─ 验证token
    ├─ 解析userType
    ├─ 验证项目权限
    └─ 允许/拒绝访问
```

## 总结

**4种用户类型的核心区分点：**

| 用户类型 | token | userType | projects | 权限范围 |
|---------|-------|----------|----------|---------|
| 未登录的游客 | 无 | - | [] | 只能访问演示项目 |
| 登录的游客 | 有 | 'guest' | [] | 只能访问演示项目 |

| 员工 | 有 | 'staff' | [有权限的项目] | 只能访问有权限的项目 |

1. 前端：`uni3/src/config/guest.js` - `isGuestUser()` 函数
