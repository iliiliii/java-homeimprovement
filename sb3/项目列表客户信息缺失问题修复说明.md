# 项目列表客户信息缺失问题修复说明

## 问题描述

调用 `/evs/projects/list?includeScheduleInfo=true` 接口时，返回的数据中只有 `customerId`，没有客户详细信息（`customer` 对象为 null）。

**返回数据示例**：
```json
{
  "id": "e0a6c982059847c9b78edb2c21a0b909",
  "name": "飞虹展厅",
  "customerId": "48374b34460847d4b8c4616becbdfaef",  // ✅ 有客户ID
  "customer": null,                                    // ❌ 客户信息为null
  "totalSchedules": 0,
  "completedSchedules": 0,
  "inProgressSchedules": 0,
  "progressRate": 0
}
```

**预期数据**：
```json
{
  "id": "e0a6c982059847c9b78edb2c21a0b909",
  "name": "飞虹展厅",
  "customerId": "48374b34460847d4b8c4616becbdfaef",
  "customer": {                                        // ✅ 应该有客户详细信息
    "id": "48374b34460847d4b8c4616becbdfaef",
    "name": "广州飞虹微电子有限公司",
    "phone": "13800138000"
  },
  "totalSchedules": 8,
  "completedSchedules": 3,
  "inProgressSchedules": 2,
  "progressRate": 38
}
```

---

## 问题原因

### 1. 后端接口设计问题

**Controller 层的逻辑**（修复前）：

```java
if ("true".equals(includeScheduleInfo)) {
    // 进度统计查询（带权限控制）
    list = projectsService.selectProjectsListWithScheduleInfo(projects);
} else if (includeRelations.length() > 0) {
    // 有关联查询参数，使用 selectProjectsWithRelations
    list = projectsService.selectProjectsWithRelations(...);
}
```

**问题分析**：
- `includeScheduleInfo` 和 `includeCustomer` 是**互斥的**
- 当传了 `includeScheduleInfo=true` 时，走第一个分支
- 第一个分支只调用 `selectProjectsListWithScheduleInfo`，**不会查询客户信息**
- 即使同时传了 `includeCustomer=true`，也会被忽略

### 2. Service 层实现问题

**selectProjectsListWithScheduleInfo 方法**（修复前）：

```java
@Override
public List<Projects> selectProjectsListWithScheduleInfo(Projects projects) {
    // 1. 查询项目列表（带权限过滤）
    List<Projects> projectsList = projectsMapper.selectProjectsList(query);
    
    // 2. 批量查询进度统计
    Map<String, Map<String, Object>> statsMap = projectsMapper.selectScheduleStatsMap(projectIds);
    
    // 3. 设置进度统计信息
    // ...
    
    return projectsList;
}
```

**问题**：
- 只调用了 `selectProjectsList`，这个方法**不会关联查询客户信息**
- 没有调用 `selectProjectsWithCustomer`

---

## 修复方案

### 方案概述

修改后端逻辑，让 `selectProjectsListWithScheduleInfo` 方法支持同时查询客户信息。

### 3. 修改 Service 实现

**文件**：`ProjectsServiceImpl.java`

**修改内容**：

```java
@Override
public List<Projects> selectProjectsListWithScheduleInfo(Projects projects, boolean includeCustomer)
{
    // 设置权限信息（自动应用权限控制）
    Projects query = setCurrentUser(projects);

    // 1. 查询项目列表（带权限过滤）
    List<Projects> projectsList;
    if (includeCustomer) {
        // ✅ 查询项目列表（包含客户信息）
        projectsList = projectsMapper.selectProjectsWithCustomer(query);
    } else {
        // 查询项目列表（不包含客户信息）
        projectsList = projectsMapper.selectProjectsList(query);
    }

    // 2. 如果无项目，直接返回
    if (projectsList.isEmpty()) {
        return projectsList;
    }

    // 3. 获取所有项目ID
    List<String> projectIds = projectsList.stream()
            .map(Projects::getId)
            .collect(Collectors.toList());

    // 4. 批量查询进度统计
    Map<String, Map<String, Object>> statsMap = projectsMapper.selectScheduleStatsMap(projectIds);

    // 5. 为每个项目设置统计信息
    for (Projects project : projectsList) {
        Map<String, Object> stats = statsMap.get(project.getId());
        if (stats != null) {
            project.setTotalSchedules(((Number) stats.get("total_count")).longValue());
            project.setCompletedSchedules(((Number) stats.get("completed_count")).longValue());
            project.setInProgressSchedules(((Number) stats.get("in_progress_count")).longValue());
            project.setProgressRate(((Number) stats.get("progress_rate")).intValue());
        } else {
            project.setTotalSchedules(0L);
            project.setCompletedSchedules(0L);
            project.setInProgressSchedules(0L);
            project.setProgressRate(0);
        }
    }

    return projectsList;
}
```

**改进点**：
- 根据 `includeCustomer` 参数决定调用哪个 Mapper 方法
- `includeCustomer=true` → 调用 `selectProjectsWithCustomer`（包含客户信息）
- `includeCustomer=false` → 调用 `selectProjectsList`（不包含客户信息）

## Mapper 层 SQL

### selectProjectsWithCustomer

**文件**：`ProjectsMapper.xml`

```xml
<select id="selectProjectsWithCustomer" parameterType="Projects" resultMap="ProjectsWithCustomerResult">
    SELECT
        p.id, p.project_type, p.name, p.customer_id, p.description, p.address,
        p.area, p.budget, p.actual_cost, p.start_date, p.end_date, p.actual_end_date,
        p.status, p.priority, p.progress, p.budgets_url, p.contracts_url,
        p.created_at, p.updated_at, p.deleted_at, p.created_by, p.updated_by,
        c.id as customer_id, c.name as customer_name, c.phone as customer_phone,
        c.email as customer_email, c.address as customer_address
    FROM projects p
    LEFT JOIN customers c ON p.customer_id = c.id
    <where>
        <!-- 权限控制逻辑 -->
        <if test="isAdmin != null and isAdmin == true">
            1=1
        </if>
        <if test="isAdmin == null or isAdmin == false">
            <if test="currentUserId != null and currentUserId != ''">
                AND p.id IN (
                    SELECT pm.project_id
                    FROM project_members pm
                    WHERE pm.user_id = #{currentUserId} AND pm.is_active = 1
                )
            </if>
        </if>
        <!-- 其他查询条件 -->
    </where>
    ORDER BY p.created_at DESC
</select>
```

**关键点**：
- 使用 `LEFT JOIN` 关联 `customers` 表
- 返回客户的详细信息（name, phone, email, address）
- 依然包含权限过滤逻辑

## 性能优化

### 优化点

1. **批量查询进度统计**
   - 使用 `selectScheduleStatsMap` 一次性查询所有项目的进度统计
   - 避免 N+1 查询问题

2. **LEFT JOIN 查询客户信息**
   - 在一条 SQL 中同时查询项目和客户信息
   - 避免循环查询客户表

3. **按需查询**
   - 只有传了 `includeCustomer=true` 才会关联查询客户表
   - 不需要客户信息时，减少数据库负担

## 总结

### 问题根源

后端接口设计时，`includeScheduleInfo` 和 `includeCustomer` 参数是互斥的，导致无法同时获取进度统计和客户信息。

### 修复方法

1. 修改 Service 方法签名，添加 `includeCustomer` 参数
2. 根据参数决定调用哪个 Mapper 方法
3. 前端同时传递两个参数

### 修复优势

1. ✅ 支持同时查询进度统计和客户信息
2. ✅ 按需查询，性能优化
3. ✅ 权限控制依然有效
4. ✅ 向后兼容（不传 `includeCustomer` 时行为不变）

### 注意事项

- 确保 `customers` 表有数据
- 确保 `projects.customer_id` 字段正确关联
- 如果客户不存在，`customer` 对象会是 null（LEFT JOIN 的特性）
