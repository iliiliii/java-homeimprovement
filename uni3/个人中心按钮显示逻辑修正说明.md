# 个人中心按钮显示逻辑修正说明

## 修正概述

根据需求对个人中心页面的按钮显示逻辑进行了修正，确保按钮显示符合业务规则。

## 修正内容

### 1. 按钮显示规则明确化

#### 修正后的显示规则
- **关于我们按钮**：一直显示，所有用户都能看到
- **退出登录按钮**：登录后一定会有，不论什么角色（客户/员工）
- **导入历史数据按钮**：只有登录成功的游客且未关联后台账户的才显示

### 2. 导入按钮显示逻辑优化

#### 修正前的问题
```javascript
// 原逻辑存在问题：判断条件不够精确
const shouldShowImportButton = computed(() => {
  const hasWechatOpenid = !!uni.getStorageSync('wechatOpenid')
  const wasGuestMode = uni.getStorageSync('wasGuestMode') === true
  return isLoggedIn.value && (hasWechatOpenid || wasGuestMode) && !userStore.userInfo.isBackendLinked
})
```

#### 修正后的逻辑
```javascript
const shouldShowImportButton = computed(() => {
  // 只有登录成功的游客并且未关联后台账户的才显示导入按钮
  if (!isLoggedIn.value) {
    return false
  }
  
  // 检查是否是从游客模式登录成功的用户
  const wasGuestMode = uni.getStorageSync('wasGuestMode') === true
  const hasWechatOpenid = !!uni.getStorageSync('wechatOpenid')
  
  // 检查是否已关联后台账户
  const isBackendLinked = userStore.userInfo.isBackendLinked !== undefined 
    ? userStore.userInfo.isBackendLinked 
    : !!(userStore.userInfo.phone && userStore.userInfo.name && userStore.userInfo.id)
  
  // 只有满足以下条件才显示导入按钮：
  // 1. 已登录
  // 2. 曾经是游客模式或有微信openid（说明是通过微信登录的）
  // 3. 未关联后台账户
  return isLoggedIn.value && (wasGuestMode || hasWechatOpenid) && !isBackendLinked
})
```

### 4. 导入数据成功后标记清理

#### 个人中心页面修正
导入数据成功后，清除所有游客相关标记：

```javascript
// 修正前：保留wasGuestMode标记
uni.setStorageSync('wasGuestMode', true) // 标记曾经是游客模式

// 修正后：清除所有游客标记
uni.removeStorageSync('wasGuestMode') // 清除游客标记，因为已经关联后台账户
```

## 业务流程说明

### 用户状态转换流程

1. **未登录用户**
   - 显示：关于我们
   - 不显示：退出登录、导入历史数据

2. **游客模式用户**
   - 显示：关于我们
   - 不显示：退出登录、导入历史数据

3. **游客登录成功（未关联后台）**
   - 显示：关于我们、退出登录、导入历史数据
   - 设置：`wasGuestMode = true`

4. **游客导入数据成功（已关联后台）**
   - 显示：关于我们、退出登录
   - 不显示：导入历史数据
   - 清除：`wasGuestMode`

5. **直接登录的用户（已关联后台）**
   - 显示：关于我们、退出登录
   - 不显示：导入历史数据

### 标记位说明

- `guestMode`：当前是否为游客模式
- `wasGuestMode`：是否曾经是游客模式（用于判断是否显示导入按钮）
- `wechatOpenid`：微信登录的openid（用于导入数据时绑定）
