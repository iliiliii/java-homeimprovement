# 登录路径修复说明

## 问题描述

错误信息：`{"errMsg":"reLaunch:fail page \"pages/login/index\" is not found"}`

**原因：** 代码中多处引用了旧的登录页面路径 `/pages/login/index`，但实际的登录页面是 `/pages/login/index-new`

## 修复内容

### 1. main.js - 路由拦截器
修复了4个拦截器中的登录页面路径：
- `navigateTo` 拦截器
- `redirectTo` 拦截器
- `reLaunch` 拦截器
- `switchTab` 拦截器

**修改：**
```javascript
// 旧路径
uni.reLaunch({ url: '/pages/login/index' })

// 新路径
uni.reLaunch({ url: '/pages/login/index-new' })
```

### 2. main.js - 白名单配置
```javascript
// 旧配置
const whiteList = [
  '/pages/login/index',
  // ...
]

// 新配置
const whiteList = [
  '/pages/login/index-new',
  // ...
]
```

### 3. utils/request.js - 重定向到登录
```javascript
// 旧代码
const redirectToLogin = () => {
  uni.reLaunch({ url: '/pages/login/index' })
}

// 新代码
const redirectToLogin = () => {
  uni.reLaunch({ url: '/pages/login/index-new' })
}
```

### 4. pages/dashboard/index.vue - 跳转登录
```javascript
// 旧代码
const goLogin = () => {
  uni.reLaunch({ url: '/pages/login/index' })
}

// 新代码
const goLogin = () => {
  uni.reLaunch({ url: '/pages/login/index-new' })
}
```

## 注意事项

1. **登录页面路径统一**
   - 所有地方都使用 `/pages/login/index-new`
   - 不要再使用 `/pages/login/index`

2. **pages.json配置**
   - 确认pages.json中配置的是 `pages/login/index-new`
   - 当前配置正确，无需修改

3. **旧文件清理**
   - 如果存在 `pages/login/index.vue` 旧文件，可以删除
   - 保留 `pages/login/index-new.vue` 作为唯一的登录页面

## 后续建议

### 1. 重命名登录页面（可选）
如果想要更简洁的路径，可以考虑：
```
pages/login/index-new.vue → pages/login/index.vue
```
然后更新所有引用为 `/pages/login/index`

### 2. 统一路径管理
建议创建一个路径常量文件：
```javascript
// utils/routes.js
export const ROUTES = {
  LOGIN: '/pages/login/index-new',
  DASHBOARD: '/pages/dashboard/index',
  PROFILE: '/pages/profile/index',
  // ...
}

// 使用
import { ROUTES } from '@/utils/routes'
uni.reLaunch({ url: ROUTES.LOGIN })
```

这样可以避免路径硬编码，便于统一管理和修改。
