# 员工登录页面显示修复说明

## 问题描述
员工登录后，dashboard页面只显示"页面加载中..."，无法正常显示员工工作台界面。

## 问题原因
1. **缺少import语句**: 缺少`watch`的导入，导致watch函数无法使用
2. **条件渲染链断裂**: Vue模板中的`v-if`/`v-else-if`条件链被破坏，导致所有用户都落入兜底状态
3. **逻辑复杂**: `shouldShowGuestView`计算属性逻辑过于复杂，容易出错

## 修复方案

### 1. 修复导入语句
```javascript
// 修复前
import { ref, computed, onMounted } from 'vue'

// 修复后  
import { ref, computed, onMounted, watch } from 'vue'
```

### 2. 重构模板条件渲染
将复杂的条件判断简化为清晰的用户状态判断：

```vue
<template>
  <view class="dashboard-page">
    <!-- 加载状态 -->
    <view v-if="loading" class="loading-mask">
      <view class="loading-spinner"></view>
    </view>
    
    <!-- 员工视图（已登录的员工） -->
    <StaffDashboard 
      v-else-if="isLoggedIn && userType === 'staff'"
      :projects="staffProjects"
      :loading="loading"
      :selected-project-id="selectedStaffProjectId"
      :loading-more="loadingMore"
      :has-more="hasMore"
      @view-project="handleViewProject"
      @select-project="handleSelectStaffProject"
    />
    
    <!-- 客户视图（已登录的客户） -->
    <CustomerDashboard 
      v-else-if="isLoggedIn && userType === 'customer'"
      :projects="projects"
      :current-project="currentProject"
      :loading="loading"
      @switch-project="handleSwitchProject"
      @navigate="navigateTo"
    />
    
    <!-- 游客用户视图（已登录的游客用户） -->
    <CustomerDashboard 
      v-else-if="isLoggedIn && userType === 'guest'"
      :projects="[]"
      :current-project="null"
      :loading="loading"
      @switch-project="handleSwitchProject"
      @navigate="navigateTo"
    />
    
    <!-- 游客页面（未登录用户） -->
    <CustomerDashboard 
      v-else
      :projects="[]"
      :current-project="null"
      :loading="loading"
      @switch-project="handleSwitchProject"
      @navigate="navigateTo"
    />
    
    <!-- 底部占位 (仅员工端需要) -->
    <view class="tab-bar-placeholder" v-if="isLoggedIn && userType === 'staff'"></view>
    
    <!-- 自定义TabBar -->
    <CustomTabBar :current="0" />
  </view>
</template>
```

### 3. 简化逻辑判断
- 添加`isLoggedIn`计算属性，直接使用userStore的状态
- 简化`onMounted`逻辑，减少复杂的条件判断
- 优化`loadDashboardData`函数，分离不同用户类型的处理逻辑

### 4. 修复条件渲染优先级
确保条件渲染按照正确的优先级执行：
1. 加载状态 (`loading`)
2. 员工视图 (`isLoggedIn && userType === 'staff'`)
3. 客户视图 (`isLoggedIn && userType === 'customer'`)
4. 游客用户视图 (`isLoggedIn && userType === 'guest'`)
5. 未登录游客页面 (兜底状态)

## 修复结果
- ✅ 员工登录后正确显示StaffDashboard组件
- ✅ 客户登录后正确显示CustomerDashboard组件
- ✅ 游客用户正确显示空项目的CustomerDashboard
- ✅ 未登录用户正确显示游客页面
- ✅ 消除"页面加载中..."的兜底状态显示

## 测试验证
1. 员工账号登录 → 显示员工工作台
2. 客户账号登录 → 显示客户首页
3. 游客账号登录 → 显示客户首页（无项目卡片）
4. 未登录状态 → 显示游客页面

## 注意事项
- 确保用户类型正确设置（'staff', 'customer', 'guest'）
- 登录状态需要通过userStore正确管理
- 不同用户类型的数据加载逻辑已分离，避免混淆
