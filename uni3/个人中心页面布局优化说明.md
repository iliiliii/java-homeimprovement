# 个人中心页面布局优化说明

## 优化目标

解决用户反馈的问题：页面存在多个可下拉的区域，用户无法正确判断下拉哪里是刷新。

## 优化方案

### 1. 移除 scroll-view 组件
- **原布局**：使用 `scroll-view` 组件包裹内容，导致页面有两层滚动（页面滚动 + scroll-view滚动）
- **新布局**：移除 `scroll-view`，使用页面原生滚动

### 2. 简化页面结构
```vue
<template>
  <view class="profile-page">
    <!-- 固定头部 -->
    <PageHeader title="个人中心" :show-back="false" />
    
    <!-- 页面内容 - 使用原生滚动 -->
    <view class="page-content">
      <!-- 项目卡片 -->
      <view class="project-brief-section" v-if="projects.length > 0">
        <ProjectCardSwiper ... />
      </view>
      
      <!-- 费用统计 -->
      <view class="expense-section" v-if="isCustomer && projects.length > 0">
        ...
      </view>
      
      <!-- 底部按钮 -->
      <view class="bottom-buttons">
        ...
      </view>
    </view>
    
    <!-- TabBar -->
    <CustomTabBar :current="3" />
  </view>
</template>
```

### 3. 样式调整

#### 原样式问题
```scss
.profile-page {
  height: 100vh;  // 固定高度
  display: flex;
  flex-direction: column;
  overflow: hidden;  // 禁止滚动
}

.scroll-content {
  flex: 1;
  height: 0;  // 强制scroll-view滚动
}
```

#### 新样式
```scss
.profile-page {
  min-height: 100vh;  // 最小高度，允许内容撑开
  background: $color-white;
  padding-bottom: 120rpx;  // 为TabBar留出空间
}

.page-content {
  padding: 16rpx 32rpx 32rpx;  // 统一内边距
}
```

### 4. 下拉刷新

保留 `onPullDownRefresh` 钩子，用户在页面任意位置下拉都会触发刷新：

```javascript
onPullDownRefresh(async () => {
  await refreshData()
  uni.stopPullDownRefresh()
})
```

## 优化效果

### 优化前
- ❌ 页面有两层滚动区域
- ❌ 用户不确定在哪里下拉刷新
- ❌ scroll-view 可能导致性能问题
- ❌ 布局复杂，难以维护

### 优化后
- ✅ 只有一个滚动区域（页面原生滚动）
- ✅ 用户在任意位置下拉都能刷新
- ✅ 性能更好，使用原生滚动
- ✅ 布局简洁，易于维护

## 代码变更

### 模板变更
1. 移除 `<scroll-view>` 组件
2. 移除 `header-placeholder` 占位元素
3. 简化内容结构，直接使用 `page-content` 包裹

### 脚本变更
1. 移除 `headerHeight` 状态
2. 移除 `updateHeaderHeight` 函数
3. 保留 `onPullDownRefresh` 钩子

### 样式变更
1. `.profile-page` 改为 `min-height: 100vh`
2. 移除 `.scroll-content` 和 `.content-wrapper` 样式
3. 添加 `.page-content` 样式
4. 移除不必要的 flex 布局

## 测试要点

1. **下拉刷新**
   - 在页面顶部下拉，应该触发刷新
   - 刷新时显示加载动画
   - 刷新完成后数据更新

2. **滚动流畅性**
   - 页面滚动应该流畅
   - 没有卡顿或跳跃
   - 滚动到底部应该能看到所有内容

3. **布局正确性**
   - 头部固定在顶部
   - TabBar固定在底部
   - 内容不被遮挡
   - 底部有足够的padding

4. **响应式**
   - 不同屏幕尺寸下布局正常
   - 内容自适应高度
   - 没有溢出或遮挡

## 注意事项

1. **PageHeader 组件**
   - PageHeader 使用 `position: fixed`，已经固定在顶部
   - 不需要额外的占位元素

2. **CustomTabBar 组件**
   - TabBar 使用 `position: fixed`，已经固定在底部
   - 页面需要 `padding-bottom` 为TabBar留出空间

3. **项目卡片轮播**
   - ProjectCardSwiper 内部有自己的滚动逻辑
   - 不受页面滚动影响

4. **游客模式**
   - 游客模式下不显示项目和费用统计
   - 只显示"导入历史数据"和"退出登录"按钮
