# 微信登录开发快速参考

## 快速开始

### 1. 核心概念

```
游客模式 (Guest Mode)
├─ 可以浏览所有内容
├─ 无需绑定账号
├─ 可选择导入历史数据
└─ 符合微信审核规范

正式用户 (Authenticated User)
├─ 已绑定账号
├─ 显示真实数据
├─ 完整功能权限
└─ 自动识别登录
```

### 2. 关键文件

```
uni3/src/
├── pages/
│   ├── login/index-new.vue      # 登录页面
│   ├── profile/index.vue        # 个人中心
│   └── dashboard/index.vue      # 首页
├── api/
│   └── auth.js                  # 认证API
├── utils/
│   └── permission.js            # 权限工具
└── store/
    └── user.js                  # 用户状态
```

## 状态管理

### 游客模式

```javascript
// 设置游客模式
uni.setStorageSync('guestMode', true)

uni.setStorageSync('wechatCode', code)

// 检查游客模式
const isGuest = uni.getStorageSync('guestMode') === true

// 清除游客模式
uni.removeStorageSync('guestMode')
uni.removeStorageSync('wechatOpenid')
uni.removeStorageSync('wechatCode')
```

### 正式用户

```javascript
// 保存登录信息（通过 userStore）

const userStore = useUserStore()

userStore.setLoginInfo({

  refreshToken,
  userType,
  userInfo,
  projects
})

// 检查登录状态
const isLoggedIn = !!userStore.token

// 退出登录
userStore.logout()
```

## 常用代码片段

### 1. 微信登录

```javascript
const handleWechatLogin = async () => {
  try {
    // 1. 获取微信code
    const loginRes = await uni.login({ provider: 'weixin' })
    
    // 2. 检查绑定状态
    const checkResult = await checkOpenidBinding(loginRes.code)
    
    // 3. 根据绑定状态决定流程
    if (checkResult.isBound) {
      // 已绑定：直接登录
      await performOpenidLogin(checkResult.openid)
    } else {
      // 未绑定：进入游客模式
      uni.setStorageSync('guestMode', true)
      uni.setStorageSync('wechatOpenid', checkResult.openid)
      uni.reLaunch({ url: '/pages/dashboard/index' })
    }
  } catch (error) {
    console.error('登录失败:', error)
    uni.showToast({ title: error.message, icon: 'none' })
  }
}
```

### 2. 导入历史数据

```javascript
const handleImportData = async (phone) => {
  try {
    // 1. 获取微信信息
    const wechatCode = uni.getStorageSync('wechatCode')
    
    // 2. 检查绑定状态
    const checkResult = await checkOpenidBinding(wechatCode)
    
    // 3. 根据绑定状态决定操作
    if (checkResult.isBound) {
      // 已绑定：直接登录
      const result = await openidLogin({
        openid: checkResult.openid,
        deviceId: getDeviceId()
      })
      userStore.setLoginInfo(result)
    } else {
      // 未绑定：执行绑定
      const result = await bindPhoneToOpenid({
        openid: checkResult.openid,
        phone: phone,
        deviceId: getDeviceId()
      })
      userStore.setLoginInfo(result)
    }
    
    // 4. 清除游客模式
    uni.removeStorageSync('guestMode')
    
    // 5. 刷新数据
    refreshData()
  } catch (error) {
    console.error('导入失败:', error)
    uni.showToast({ title: error.message, icon: 'none' })
  }
}
```

### 3. 页面初始化

```javascript
onMounted(() => {
  // 检查游客模式
  const isGuest = uni.getStorageSync('guestMode') === true
  
  if (isGuest) {
    // 游客模式：不加载数据或显示示例数据
    console.log('游客模式')
    return
  }
  
  // 正式用户：加载真实数据
  loadData()
})
```

### 4. 退出登录

```javascript
const handleLogout = () => {
  uni.showModal({
    title: '提示',
    content: '确定要退出登录吗？',
    success: (res) => {
      if (res.confirm) {
        // 清除游客模式
        uni.removeStorageSync('guestMode')
        uni.removeStorageSync('wechatCode')
        uni.removeStorageSync('wechatOpenid')
        
        // 清除用户信息
        userStore.logout()
        
        // 跳转登录页
        uni.reLaunch({ url: '/pages/login/index-new' })
      }
    }
  })
}
```

## 常见问题

### Q1: 如何判断当前是否游客模式？

```javascript
const isGuest = uni.getStorageSync('guestMode') === true
```

### Q2: 游客模式下如何显示数据？

```javascript
if (isGuestMode()) {
  // 方案1: 显示空数据
  projects.value = []
  
  // 方案2: 显示示例数据
  projects.value = [{ id: 'demo', name: '示例项目' }]
  
  // 方案3: 显示引导提示
  showImportGuide.value = true
}
```

### Q3: 如何获取设备ID？

```javascript
const getDeviceId = () => {
  let deviceId = uni.getStorageSync('deviceId')
  if (!deviceId) {
    deviceId = 'device_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9)
    uni.setStorageSync('deviceId', deviceId)
  }
  return deviceId
}
```

### Q4: 如何处理 token 过期？

```javascript
// 在 request.js 中统一处理
if (response.code === 401) {
  // token 过期
  userStore.logout()
  uni.reLaunch({ url: '/pages/login/index-new' })
}
```

### Q5: 如何实现自动登录？

```javascript
onMounted(async () => {
  // 检查是否主动退出
  const manualLogout = uni.getStorageSync('manualLogout')
  if (manualLogout) {
    uni.removeStorageSync('manualLogout')
    return
  }
  
  // 检查游客模式
  const isGuest = uni.getStorageSync('guestMode')
  if (isGuest) {
    uni.reLaunch({ url: '/pages/dashboard/index' })
    return
  }
  
  // 检查 token
  const token = uni.getStorageSync('token')
  if (token) {
    await userStore.validateToken()
    uni.reLaunch({ url: '/pages/dashboard/index' })
    return
  }
  
  // 显示登录页
  bindingStep.value = 'normal'
})
```

## 错误处理

### 常见错误码

```javascript
const ERROR_CODES = {
  401: '登录已过期',
  403: '无权限访问',
  404: '接口不存在',
  500: '服务器错误',
  1001: '账号未注册',
  1002: '账号已绑定其他微信',
  1003: '微信已绑定其他账号',
  1004: '账号已禁用',
  1005: '账号已锁定'
}
```

### 错误处理示例

```javascript
try {
  await someApiCall()
} catch (error) {
  console.error('操作失败:', error)
  
  // 根据错误类型处理
  if (error.code === 1001) {
    // 账号未注册
    uni.showModal({
      title: '账号未注册',
      content: '请联系管理员添加账号',
      confirmText: '联系管理员',
      success: (res) => {
        if (res.confirm) {
          showContactAdmin()
        }
      }
    })
  } else if (error.code === 1002) {
    // 账号已绑定其他微信
    uni.showModal({
      title: '绑定失败',
      content: '该账号已绑定其他微信账号',
      showCancel: false
    })
  } else {
    // 其他错误
    uni.showToast({
      title: error.message || '操作失败',
      icon: 'none'
    })
  }
}
```

## 性能优化

### 1. 减少网络请求

```javascript
// 缓存绑定状态检查结果
let bindingCheckCache = null
let bindingCheckTime = 0

const checkOpenidBindingWithCache = async (code) => {
  const now = Date.now()
  
  // 5分钟内使用缓存
  if (bindingCheckCache && now - bindingCheckTime < 5 * 60 * 1000) {
    return bindingCheckCache
  }
  
  // 重新检查
  bindingCheckCache = await checkOpenidBinding(code)
  bindingCheckTime = now
  
  return bindingCheckCache
}
```

## 安全建议

### 1. 敏感信息处理

```javascript
// ❌ 不要在控制台输出敏感信息
console.log('token:', token)
console.log('openid:', openid)

// ✅ 使用脱敏处理
console.log('token:', token.substr(0, 10) + '...')
console.log('openid:', openid.substr(0, 10) + '...')
```

### 2. 数据验证

```javascript
// 验证手机号
const validatePhone = (phone) => {
  return /^1[3-9]\d{9}$/.test(phone)
}

// 验证 openid
const validateOpenid = (openid) => {
  return openid && openid.length > 0
}
```

### 3. 防止重复提交

```javascript
let submitting = false

const handleSubmit = async () => {
  if (submitting) return
  
  try {
    submitting = true
    await submitData()
  } finally {
    submitting = false
  }
}
```
