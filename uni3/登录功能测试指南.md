# 登录功能测试指南

## 测试环境准备

### 1. 清除所有缓存
```javascript
// 在微信开发者工具控制台执行
uni.clearStorageSync()
```

### 2. 重启小程序
- 关闭小程序
- 重新编译运行

## 测试场景

### 场景1：首次使用（游客模式）

**操作步骤：**
1. 打开小程序
2. 进入登录页面
3. 勾选用户协议
4. 点击"微信登录"按钮

**预期结果：**
- ✅ 显示"登录成功"提示
- ✅ 自动跳转到首页（dashboard）
- ✅ 可以浏览所有页面
- ✅ 显示示例数据或通用内容
- ✅ 个人中心显示"导入历史数据"按钮

**验证点：**
```javascript
// 检查游客模式标记
console.log('游客模式:', uni.getStorageSync('guestMode')) // 应该是 true

// 检查微信code
console.log('微信Code:', uni.getStorageSync('wechatCode')) // 应该有值

// 检查token
console.log('Token:', uni.getStorageSync('token')) // 应该为空
```

### 场景2：游客浏览功能

**操作步骤：**
1. 在游客模式下
2. 依次访问各个页面：
   - 首页（dashboard）
   - 施工进度（schedule）
   - 设计图库（design）
   - 购物清单（shopping）
   - 施工日志（log）
   - 个人中心（profile）

**预期结果：**
- ✅ 所有页面都可以正常访问
- ✅ 不会被拦截或跳转到登录页
- ✅ 显示适当的示例数据
- ✅ 功能演示正常

### 场景3：导入历史数据

**操作步骤：**
1. 在游客模式下进入个人中心
2. 点击"导入历史数据"按钮
3. 在引导弹窗中点击"开始导入"
4. 输入已注册的手机号（如：13800138000）
5. 点击"确认导入"

**预期结果：**
- ✅ 显示"正在导入数据..."加载提示
- ✅ 导入成功后显示"历史数据导入成功"
- ✅ 游客模式标记被清除
- ✅ 保存了token和用户信息
- ✅ 页面数据自动刷新为真实数据
- ✅ "导入历史数据"按钮消失

**验证点：**
```javascript
// 检查游客模式标记
console.log('游客模式:', uni.getStorageSync('guestMode')) // 应该是 false 或不存在

// 检查token
console.log('Token:', uni.getStorageSync('token')) // 应该有值

// 检查用户信息
console.log('用户信息:', uni.getStorageSync('userInfo')) // 应该有完整信息
```

### 场景4：导入失败 - 手机号未注册

**操作步骤：**
1. 在游客模式下进入个人中心
2. 点击"导入历史数据"
3. 输入未注册的手机号（如：19999999999）
4. 点击"确认导入"

**预期结果：**
- ✅ 显示"手机号未注册"提示
- ✅ 提供"重新输入"和"取消"选项
- ✅ 点击"重新输入"可以再次输入
- ✅ 游客模式保持不变

### 场景5：退出登录后重新进入

**操作步骤：**
1. 在正式用户状态下
2. 进入个人中心
3. 点击"退出登录"
4. 确认退出
5. 重新打开小程序

**预期结果：**
- ✅ 跳转到登录页面
- ✅ 游客模式标记被清除
- ✅ token被清除
- ✅ 不会自动登录

### 场景6：已导入数据后再次打开

**操作步骤：**
1. 已经导入历史数据的用户
2. 关闭小程序
3. 重新打开小程序

**预期结果：**
- ✅ 自动验证token
- ✅ 直接进入首页
- ✅ 显示真实的用户数据
- ✅ 不显示"导入历史数据"按钮

### 场景7：取消导入数据

**操作步骤：**
1. 在游客模式下进入个人中心
2. 点击"导入历史数据"
3. 在引导弹窗中点击"稍后导入"
4. 或在手机号输入框点击"取消"

**预期结果：**
- ✅ 弹窗关闭
- ✅ 保持游客模式
- ✅ 可以继续浏览
- ✅ 下次仍可以点击导入

## API接口测试

### 1. 绑定接口测试

**请求参数：**
```json
{
  "code": "微信登录code",
  "phone": "13800138000",
  "deviceId": "device_xxx"
}
```

**成功响应：**
```json
{
  "code": 200,
  "data": {
    "accessToken": "xxx",
    "refreshToken": "xxx",
    "userType": "customer",
    "userInfo": {
      "id": "1",
      "name": "张三",
      "phone": "13800138000",
      "avatar": ""
    },
    "projects": [...]
  }
}
```

**失败响应（手机号未注册）：**
```json
{
  "code": 400,
  "msg": "手机号未在系统中注册"
}
```

## 边界情况测试

### 1. 微信code过期
**场景：** 游客模式下，长时间后才点击导入数据

**预期：**
- 提示"微信登录信息已过期，请重新登录"
- 引导用户退出后重新登录

### 2. 网络异常
**场景：** 导入数据时网络断开

**预期：**
- 显示网络错误提示
- 保持游客模式
- 可以重试

### 3. 重复导入
**场景：** 已经导入数据的用户再次尝试导入

**预期：**
- 不显示"导入历史数据"按钮
- 或显示"已导入"状态

## 审核前检查清单

### 功能检查
- [ ] 微信登录可以直接进入（无验证）
- [ ] 游客可以访问所有页面
- [ ] "导入历史数据"按钮位置正确
- [ ] 导入流程文案合规
- [ ] 没有"绑定"、"关联"等敏感词

### 文案检查
- [ ] 使用"导入历史数据"而非"绑定账号"
- [ ] 使用"查看历史项目"而非"关联微信"
- [ ] 使用"温馨提示"而非"重要提示"
- [ ] 所有提示都是可选的，非强制的

### 交互检查
- [ ] 没有强制弹窗
- [ ] 没有诱导性引导
- [ ] 用户可以随时取消
- [ ] 没有外部跳转

### 数据检查
- [ ] 游客模式下显示示例数据
- [ ] 示例数据有实际意义
- [ ] 导入后数据正确切换
- [ ] 退出登录清除数据

## 常见问题排查

### 问题1：点击微信登录后没有跳转
**排查：**
1. 检查是否勾选了用户协议
2. 查看控制台是否有错误
3. 检查微信登录接口是否正常

### 问题2：导入数据后仍显示示例数据
**排查：**
1. 检查游客模式标记是否清除
2. 检查token是否保存
3. 检查页面是否刷新数据

### 问题3：退出登录后自动重新登录
**排查：**
1. 检查manualLogout标记
2. 检查游客模式标记是否清除
3. 检查登录页面的逻辑
