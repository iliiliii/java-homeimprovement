# 客户用户项目卡片显示调试说明

## 问题描述

用户类型为 `customer` 的用户在首页无法看到项目卡片，需要调试确认问题所在。

## 调试步骤

### 1. 确认用户状态
根据日志显示：
- `用户类型: customer` ✅
- `已登录: true` ✅
- `shouldShowGuestView: false` ✅

用户状态正常，应该显示客户页面。

### 2. 确认数据加载逻辑
Dashboard页面的数据加载逻辑：
```javascript
if (userType.value === 'customer' || userType.value === 'guest') {
  if (userType.value === 'guest') {
    // 游客用户，设置空数据
    projects.value = []
  } else {
    // 正式客户用户调用API获取数据
    const data = await getCustomerDashboard()
    projects.value = data?.projects || []
  }
}
```

对于 `customer` 用户，会调用 `getCustomerDashboard()` API。

### 3. 确认项目卡片显示条件
CustomerDashboard组件的显示条件：
```vue
<ProjectCardSwiper
  v-if="projects.length > 0 && !isGuestMode"
  :projects="projects"
/>
```

显示条件：
- `projects.length > 0` - 有项目数据
- `!isGuestMode` - 非游客模式

### 4. 确认游客模式判断
```javascript
const isGuestMode = computed(() => {
  const guestMode = uni.getStorageSync('guestMode') === true
  const isGuestUser = userStore.userType === 'guest'
  return guestMode || isGuestUser
})
```

对于 `userType: "customer"` 的用户：
- `guestMode` 应该为 `false`
- `isGuestUser` 应该为 `false`
- `isGuestMode` 应该为 `false`

## 可能的问题点

### 1. API数据问题
- `getCustomerDashboard()` API 返回的数据为空
- API 调用失败
- 数据格式不正确

### 2. 数据传递问题
- Dashboard页面没有正确传递项目数据给CustomerDashboard组件
- Props传递过程中数据丢失

### 3. 组件渲染问题
- 游客模式判断逻辑错误
- 显示条件计算错误
- Vue响应式更新问题

### 4. 时序问题
- 组件渲染时项目数据还未加载完成
- 异步数据更新时机问题

## 调试建议

1. **检查API响应**：确认 `getCustomerDashboard()` 返回的数据结构和内容
2. **检查数据传递**：确认Dashboard页面是否正确传递了项目数据
3. **检查显示条件**：确认所有显示条件都满足
4. **检查组件状态**：确认CustomerDashboard组件的内部状态

## 下一步行动

根据调试日志的输出结果，可以确定问题的具体位置：
- 如果API数据正常但组件不显示 → 检查组件显示逻辑
- 如果API数据为空 → 检查后端数据或API调用
- 如果数据传递有问题 → 检查Props传递逻辑
