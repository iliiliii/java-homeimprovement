# 游客登录状态修正说明

## 问题分析

根据日志显示，游客进行微信登录后出现了状态不一致的问题：
- `游客模式: true` （应该在登录成功后变为false）
- `已登录: false` （应该在登录成功后变为true）
- `hasWechatOpenid: true` （说明微信登录获取了openid）
- 用户信息为空：`{id: "", name: "", phone: "", avatar: ""}`

## 问题原因

原来的游客登录逻辑有问题：
1. 游客微信登录成功后，仍然设置 `guestMode: true`
2. 没有设置用户为已登录状态
3. 没有创建基本的用户信息

## 修正方案

### 1. 修正登录页面的游客登录逻辑

#### 修正前
```javascript
// 未绑定，进入游客模式
uni.setStorageSync('guestMode', true) // 错误：应该清除游客模式
// 没有设置登录状态
```

#### 修正后
```javascript
// 未绑定，游客登录成功
// 清除游客模式标记，设置已登录游客标记
uni.removeStorageSync('guestMode')
uni.setStorageSync('wasGuestMode', true)

// 设置基本的登录状态（游客登录成功，但未关联后台账户）
const guestLoginInfo = {
  accessToken: 'guest_token_' + Date.now(),
  refreshToken: 'guest_refresh_token_' + Date.now(),
  expiresIn: 7200,
  userType: 'guest', // 设置为游客类型
  userInfo: {
    id: 'guest_' + Date.now(),
    name: '游客用户',
    phone: '',
    avatar: '',
    isBackendLinked: false // 明确标记未关联后台账户
  },
  projects: [] // 游客没有项目数据
}

// 保存登录信息到store
userStore.setLoginInfo(guestLoginInfo)
```

### 2. 优化个人中心按钮显示逻辑

#### 修正导入按钮显示条件
```javascript
const shouldShowImportButton = computed(() => {
  if (!isLoggedIn.value) return false
  
  // 检查是否是游客用户或从游客模式登录成功的用户
  const wasGuestMode = uni.getStorageSync('wasGuestMode') === true
  const hasWechatOpenid = !!uni.getStorageSync('wechatOpenid')
  const isGuestUser = userStore.userType === 'guest'
  
  // 检查是否已关联后台账户
  const isBackendLinked = userStore.userInfo.isBackendLinked !== undefined 
    ? userStore.userInfo.isBackendLinked 
    : !!(userStore.userInfo.phone && userStore.userInfo.name && userStore.userInfo.id && !userStore.userInfo.id.startsWith('guest_'))
  
  return isLoggedIn.value && (isGuestUser || wasGuestMode || hasWechatOpenid) && !isBackendLinked
})
```

### 3. 更新dashboard页面显示逻辑

```javascript
const shouldShowGuestView = computed(() => {
  const isGuest = uni.getStorageSync('guestMode') === true
  const isLoggedIn = userStore.isLoggedIn
  
  // 只有未登录用户或处于游客模式（未进行微信登录）的用户显示游客页面
  // 已登录的游客用户应该显示对应的用户页面
  return !isLoggedIn || isGuest
})
```

## 修正后的状态流转

### 1. 未登录状态
- `guestMode: undefined`
- `isLoggedIn: false`
- `userType: ""`
- 显示：游客页面 + 登录引导

### 2. 游客模式（未进行微信登录）
- `guestMode: true`
- `isLoggedIn: false`
- `userType: ""`
- 显示：游客页面 + 登录引导

### 3. 游客登录成功（未关联后台）
- `guestMode: false`
- `isLoggedIn: true`
- `userType: "guest"`
- `wasGuestMode: true`
- `isBackendLinked: false`
- 显示：客户页面 + 关于我们 + 退出登录 + 导入历史数据

### 4. 游客导入数据成功（已关联后台）
- `guestMode: false`
- `isLoggedIn: true`
- `userType: "customer"` 或 `"staff"`
- `wasGuestMode: false`（已清除）
- `isBackendLinked: true`
- 显示：对应角色页面 + 关于我们 + 退出登录

## 按钮显示规则（修正后）

| 用户状态 | guestMode | isLoggedIn | userType | 关于我们 | 退出登录 | 导入历史数据 |
|---------|-----------|------------|----------|---------|---------|-------------|
| 未登录 | undefined | false | "" | ✅ | ❌ | ❌ |
| 游客模式 | true | false | "" | ✅ | ❌ | ❌ |
| 游客登录成功 | false | true | "guest" | ✅ | ✅ | ✅ |
| 游客导入成功 | false | true | "customer"/"staff" | ✅ | ✅ | ❌ |
| 直接登录 | false | true | "customer"/"staff" | ✅ | ✅ | ❌ |

## 测试验证

修正后，游客登录流程应该是：

1. **游客模式下点击登录**
   - 进行微信授权
   - 检查openid绑定状态
   - 如果未绑定，创建游客登录状态

2. **登录成功后查看个人中心**
   - 应该显示：关于我们 + 退出登录 + 导入历史数据
   - 调试日志应该显示：`isLoggedIn: true, userType: "guest", shouldShowImportButton: true`

3. **点击导入历史数据**
   - 输入手机号进行绑定
   - 绑定成功后清除游客标记
   - 按钮变为：关于我们 + 退出登录
