# 游客模式个人中心重定向问题修复

## 问题描述

**现象：** 游客账户点击"我的"菜单进入个人中心页面时，提示"获取项目数据失败: Error: 登录已过期"，然后被重定向到登录页面。

**错误日志：**
```
index.js? [sm]:95 获取项目数据失败: Error: 登录已过期
```

## 问题分析

### 问题流程

```
游客点击"我的"
  ↓
进入 pages/profile/index
  ↓
onMounted 执行
  ↓
调用 loadProjectData()
  ↓
调用 getCustomerDashboard() API
  ↓
游客模式没有token
  ↓
API返回401或token过期错误
  ↓
request.js 的 handleTokenRefresh()
  ↓
没有refreshToken
  ↓
调用 redirectToLogin()
  ↓
清除所有缓存（包括游客模式标记）
  ↓
跳转到登录页 ❌
```

### 根本原因

1. **个人中心页面无条件加载数据**
   ```javascript
   onMounted(() => {
     loadProjectData() // ❌ 游客模式下也会调用
   })
   ```

2. **API调用失败触发重定向**
   ```javascript
   const handleTokenRefresh = async (originalConfig) => {
     if (!refreshToken) {
       redirectToLogin() // ❌ 游客模式也会跳转
       return Promise.reject(new Error('登录已过期'))
     }
   }
   ```

3. **redirectToLogin清除游客标记**
   ```javascript
   const redirectToLogin = () => {
     // 清除所有缓存，包括游客模式标记
     uni.removeStorageSync('token')
     // ... 其他清除
     uni.reLaunch({ url: '/pages/login/index-new' })
   }
   ```

## 修复方案

### 1. 个人中心页面 - 添加游客模式检查

**文件：** `uni3/src/pages/profile/index.vue`

#### 修复 onMounted
```javascript
onMounted(() => {
  // 预估初始高度
  const sys = uni.getSystemInfoSync()
  headerHeight.value = (sys.statusBarHeight || 20) + 56
  
  // 获取精确高度
  setTimeout(updateHeaderHeight, 200)
  
  // 检查是否是游客模式
  const isGuest = uni.getStorageSync('guestMode') === true
  
  if (isGuest) {
    // 游客模式，不加载项目数据
    console.log('[Profile] 游客模式，不加载项目数据')
    return
  }
  
  // 正式用户，加载项目数据
  loadProjectData()
})
```

#### 修复 refreshData
```javascript
const refreshData = async () => {
```

### 2. 请求工具 - 游客模式不跳转登录

**文件：** `uni3/src/utils/request.js`

#### 修复 redirectToLogin
```javascript
const redirectToLogin = () => {
  // 检查是否是游客模式
  const isGuest = uni.getStorageSync('guestMode') === true
  
  if (isGuest) {
    // 游客模式下，不跳转登录页，只是返回错误
    console.log('[Request] 游客模式，API调用失败但不跳转登录页')
    return
  }
  
  // 清除登录信息
  uni.removeStorageSync('token')
  uni.removeStorageSync('refreshToken')
  // ... 其他清除
  
  // 跳转登录页
  uni.reLaunch({ url: '/pages/login/index-new' })
}
```

## 错误处理优化

### 当前问题
- API调用失败直接跳转登录页
- 没有区分游客模式和正式用户
- 清除了游客模式标记

### 优化方案
```javascript
const handleTokenRefresh = async (originalConfig) => {
  const refreshToken = uni.getStorageSync('refreshToken')
  const isGuest = uni.getStorageSync('guestMode') === true
  
  if (!refreshToken) {
    if (isGuest) {
      // 游客模式，只返回错误，不跳转
      return Promise.reject(new Error('游客模式无权限'))
    } else {
      // 正式用户，跳转登录
      redirectToLogin()
      return Promise.reject(new Error('登录已过期'))
    }
  }
  
  // 尝试刷新token
  // ...
}
```

## 注意事项

### 1. 游客模式标记保护
- 游客模式下API调用失败不应清除游客标记
- 只有用户主动退出登录才清除

### 2. 错误提示友好
- 游客模式下API失败不显示错误提示
- 或显示友好的引导提示

### 3. 数据加载策略
- 游客模式下不调用需要token的API
- 避免不必要的错误和重定向

### 4. 页面状态管理
- 游客模式下显示空状态或引导
- 正式用户显示真实数据
