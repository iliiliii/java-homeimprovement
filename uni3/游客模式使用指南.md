# 游客模式使用指南

## 功能说明

游客模式允许用户在不登录的情况下体验部分功能，符合微信小程序"用完即走"的设计理念。

## 游客模式可访问的功能

### ✅ 可以使用的功能
1. **首页浏览** - 查看公司介绍和服务概览
2. **设计图库** - 浏览装修设计案例和效果图
3. **品牌展示** - 了解合作品牌和产品信息
4. **公司信息** - 查看联系方式和服务范围

### ❌ 需要登录的功能
1. **项目详情** - 个人项目信息和进度
2. **施工进度** - 实时施工状态和时间轴
3. **质检记录** - 质量检查报告和整改记录
4. **购物清单** - 材料采购和预算管理
5. **施工日志** - 详细的施工记录和照片
6. **个人中心** - 用户信息和设置

## 实现方式

### 1. 权限控制
```javascript
// 在 utils/permission.js 中
export const isGuestMode = () => {
  return uni.getStorageSync('guestMode') === true
}

export const hasFeaturePermission = (feature) => {
  const guestRestrictedFeatures = [
    'project-detail',
    'schedule-detail', 
    'quality-check',
    // ...
  ]
  
  if (isGuestMode()) {
    return !guestRestrictedFeatures.includes(feature)
  }
  
  return true
}
```

### 2. 页面使用示例
```javascript
// 在需要权限控制的页面中
import { isGuestMode, promptLogin } from '@/utils/permission'

const handleProjectDetail = () => {
  if (isGuestMode()) {
    promptLogin('查看项目详情需要登录')
    return
  }
  
  // 正常业务逻辑
  uni.navigateTo({ url: '/pages/project/detail' })
}
```

### 3. 组件中的权限控制
```vue
<template>
  <view>
    <!-- 游客可见内容 -->
    <view class="public-content">
      <text>设计案例展示</text>
    </view>
    
    <!-- 登录后可见内容 -->
    <view v-if="!isGuestMode" class="private-content">
      <text>您的项目进度</text>
    </view>
    
    <!-- 游客提示 -->
    <view v-if="isGuestMode" class="guest-tip" @click="promptLogin">
      <text>登录查看更多功能</text>
    </view>
  </view>
</template>
```

## 用户体验优化

### 1. 友好的提示信息
- 在受限功能处显示"登录后可使用"提示
- 提供一键跳转登录的便捷入口
- 说明登录后可获得的额外功能

### 2. 无缝的登录转换
- 游客模式下点击受限功能时，友好提示并引导登录
- 登录成功后自动跳转到用户想要访问的功能
- 保持用户的操作连续性

### 3. 清晰的功能边界
- 明确标识哪些功能需要登录
- 在游客模式下隐藏或置灰受限功能
- 提供功能说明和登录引导

## 审核合规性

### 符合微信小程序规范
1. **降低使用门槛** - 用户可以先体验再决定是否登录
2. **用完即走** - 不强制用户必须登录才能使用
3. **功能透明** - 清楚说明哪些功能需要登录
4. **用户自主选择** - 用户可以自由选择是否登录

### 避免审核风险
1. **不强制绑定** - 游客模式提供了不绑定的选择
2. **不诱导跳出** - 所有功能都在小程序内完成
3. **功能实用** - 游客模式下仍有实际可用的功能
4. **体验友好** - 不会因为不登录而影响基本使用

## 注意事项

1. **数据安全** - 游客模式下不存储敏感信息
2. **功能限制** - 合理设置游客模式的功能边界
3. **引导登录** - 适时引导用户登录获得完整体验
4. **清除机制** - 用户登录时自动清除游客模式标记
