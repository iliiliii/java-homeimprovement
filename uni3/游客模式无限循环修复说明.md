# 游客模式无限循环修复说明

## 问题描述

**现象：** 登录后一直卡在 `[登录页面] 检测到游客模式，跳转首页`，无限循环

**日志：**
```
index-new.js? [sm]:56 [登录页面] 检测到游客模式，跳转首页
```

## 问题原因

### 循环流程
```
登录页面
  ↓ 检测到游客模式
跳转到首页 (reLaunch)
  ↓ 路由拦截器检查
isLoggedIn() 返回 false
  ↓ 拦截器判断未登录
跳转到登录页 (reLaunch)
  ↓ 检测到游客模式
跳转到首页 (reLaunch)
  ↓ 无限循环...
```

### 根本原因

1. **isLoggedIn() 逻辑问题**
   ```javascript
   // 旧代码
   export const isLoggedIn = () => {
     if (isGuestMode()) return false  // ❌ 游客模式返回false
     const userStore = useUserStore()
     return !!userStore.token
   }
   ```
   游客模式下返回 `false`，导致路由拦截器认为未登录

2. **首页token检查问题**
   ```javascript
   // 旧代码
   if (!userStore.token) {  // ❌ 游客模式没有token
     loading.value = false
     return
   }
   ```
   游客模式下没有token，显示"请先登录"

## 修复方案

### 1. 修改 isLoggedIn() 函数

**文件：** `uni3/src/utils/permission.js`

```javascript
/**
 * 检查是否已登录（游客模式也视为已登录）
 * @returns {Boolean}
 */
export const isLoggedIn = () => {
  // 游客模式视为已登录
  if (isGuestMode()) return true  // ✅ 游客模式返回true
  
  // 正式用户检查token
  const userStore = useUserStore()
  return !!userStore.token
}
```

**关键改动：**
- 游客模式下返回 `true`
- 让路由拦截器放行游客模式的跳转

### 2. 修改首页初始化逻辑

**文件：** `uni3/src/pages/dashboard/index.vue`

```javascript
onMounted(async () => {
  // 先从本地存储恢复用户状态
  userStore.initFromStorage()
  
  // 检查是否是游客模式
  const isGuest = uni.getStorageSync('guestMode') === true
  
  if (isGuest) {
    // 游客模式，设置为客户类型
    userType.value = 'customer'
    console.log('[Dashboard] 游客模式，显示客户视图')
    loading.value = false
    // 游客模式下可以显示示例数据或空状态
    return
  }
  
  userType.value = userStore.userType
  
  // 如果没有登录，跳转登录页
  if (!userStore.token) {
    loading.value = false
    return
  }
  
  await loadDashboardData()
})
```

**关键改动：**
- 优先检查游客模式
- 游客模式下设置为客户类型
- 不加载真实数据，显示空状态或示例数据

## 修复后的流程

### 正常流程
```
登录页面
  ↓ 检测到游客模式
跳转到首页 (reLaunch)
  ↓ 路由拦截器检查
isLoggedIn() 返回 true ✅
  ↓ 放行
首页加载
  ↓ 检测到游客模式
显示客户视图（空状态）✅
```

### 游客模式特点
1. `isLoggedIn()` 返回 `true` - 通过路由拦截
2. `userType` 设置为 `'customer'` - 显示客户视图
3. 不加载真实数据 - 显示空状态或示例数据
4. 可以访问所有页面 - 无限制

## 注意事项

### 1. 路由拦截器
- 游客模式必须被视为"已登录"
- 否则会被拦截器拦截

### 2. 页面初始化
- 优先检查游客模式
- 游客模式下不调用需要token的API
- 避免API调用失败

### 3. 数据展示
- 游客模式下显示友好的空状态
- 提供"导入历史数据"的引导
- 不要让用户感觉被欺骗

### 4. 用户体验
- 游客模式下功能完整可用
- 页面切换流畅
- 引导自然不强制
