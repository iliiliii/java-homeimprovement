# 小程序更新功能说明

## 功能概述

为uni3小程序项目添加了完整的版本更新管理功能，使用微信小程序的 `uni.getUpdateManager()` API 实现自动检查和更新。

## 实现方案

### 1. 全局更新检查（推荐方案）

更新逻辑已集成到 `App.vue` 中，在应用启动时自动初始化：

**位置**: `uni3/src/App.vue`

**特点**:
- 应用启动时自动检查更新
- 全局生效，无需在每个页面单独配置
- 从后台切换到前台时确保监听器已注册
- 完整的更新流程处理

**更新流程**:
```
1. 小程序启动 (onLaunch)
   ↓
2. 初始化更新管理器
   ↓
3. 微信自动检查更新
   ↓
4. 发现新版本 → 自动下载
   ↓
5. 下载完成 → 弹窗提示用户
   ↓
6. 用户确认 → 重启应用更新
   或
   用户取消 → 下次启动时更新
```

### 2. 工具类方案（可选）

创建了独立的更新管理工具类，方便在特定页面使用：

**位置**: `uni3/src/utils/updateManager.js`

**使用场景**:
- 需要在特定页面手动触发更新检查
- 需要自定义更新提示UI
- 需要更灵活的更新控制

## 核心功能

### 1. 自动检查更新
- 小程序冷启动时自动检查
- 无需手动触发
- 静默检查，不打扰用户

### 2. 新版本下载
- 发现新版本后自动下载
- 显示"发现新版本"提示
- 下载过程在后台进行

### 3. 更新提示
- 下载完成后弹窗提示用户
- 提供"立即重启"和"稍后"两个选项
- 用户友好的交互体验

### 4. 更新失败处理
- 捕获下载失败错误
- 提示用户删除小程序重新打开
- 完善的错误处理机制

## 使用方法

### 方法一：全局自动更新（已配置）

无需任何额外操作，更新功能已在 `App.vue` 中自动启用。

### 方法二：在特定页面使用工具类

如果需要在某个页面（如设置页面）添加"检查更新"按钮：

```vue
<template>
  <view>
    <button @click="handleCheckUpdate">检查更新</button>
  </view>
</template>

<script setup>
import updateManager from '@/utils/updateManager.js'

// 初始化（可选，App.vue已初始化）
const initUpdate = () => {
  updateManager.init({
    silent: false, // 显示检查结果
    onCheckForUpdate: (res) => {
      console.log('检查更新回调:', res)
    },
    onUpdateReady: () => {
      console.log('更新准备就绪')
      // 可以自定义更新提示UI
    },
    onUpdateFailed: (err) => {
      console.error('更新失败:', err)
    }
  })
}

// 手动检查更新
const handleCheckUpdate = () => {
  updateManager.checkForUpdate()
}
</script>
```

### 方法三：自定义更新UI

```javascript
import updateManager from '@/utils/updateManager.js'

// 初始化时传入自定义回调
updateManager.init({
  silent: true,
  onUpdateReady: () => {
    // 自定义更新提示
    uni.showModal({
      title: '发现新版本',
      content: '新版本包含重要更新，建议立即更新',
      confirmText: '立即更新',
      cancelText: '暂不更新',
      success: (res) => {
        if (res.confirm) {
          updateManager.applyUpdate()
        }
      }
    })
  }
})
```

## API 说明

### updateManager.init(options)

初始化更新管理器

**参数**:
- `options.silent` (Boolean): 是否静默检查，默认 true
- `options.onCheckForUpdate` (Function): 检查更新回调
- `options.onUpdateReady` (Function): 更新准备就绪回调
- `options.onUpdateFailed` (Function): 更新失败回调

### updateManager.checkForUpdate()

手动触发更新检查（微信会自动检查，此方法仅用于特殊场景）

### updateManager.applyUpdate()

应用更新，强制小程序重启

### updateManager.showUpdateDialog()

显示默认的更新提示对话框

### updateManager.reset()

重置管理器（用于测试）

## 注意事项

### 1. 平台限制
- 仅在微信小程序环境生效
- 使用条件编译 `#ifdef MP-WEIXIN` 确保兼容性
- 其他平台（H5、App）会自动跳过

### 2. 更新时机
- 微信小程序会在冷启动时自动检查更新
- 无需手动调用检查接口
- 热启动（从后台切换到前台）不会触发检查

### 3. 用户体验
- 检查更新过程静默进行
- 仅在发现新版本时提示用户
- 用户可以选择立即更新或稍后更新
- 下次启动时会自动应用更新

### 4. 测试建议
- 开发环境无法测试更新功能
- 需要发布体验版或正式版进行测试
- 建议在体验版测试完整更新流程

### 5. 最佳实践
- 保持全局更新检查（App.vue）
- 避免频繁手动检查更新
- 更新提示文案要清晰友好
- 处理好更新失败的情况
