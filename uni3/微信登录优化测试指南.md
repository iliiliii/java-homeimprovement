1. 清除小程序缓存（开发工具：清除缓存 → 全部清除）

3. 点击"微信登录"按钮

## 常见问题排查

### 问题1: 点击微信登录无反应
**排查步骤**:
1. 检查控制台是否有错误日志
2. 检查网络连接是否正常
3. 检查微信登录凭证是否获取成功
4. 检查 API 接口是否正常

### 问题2: 游客模式无法访问某些页面
**排查步骤**:
1. 检查 `permission.js` 中的 `isLoggedIn()` 函数
2. 检查路由拦截器配置
3. 检查页面的 `onMounted` 逻辑

### 问题3: 导入数据后仍显示游客模式
**排查步骤**:
1. 检查 `guestMode` 是否已清除
2. 检查 token 是否已保存
3. 检查 `userStore.setLoginInfo()` 是否正确调用
4. 检查页面是否已刷新

### 问题4: 已绑定用户仍进入游客模式
**排查步骤**:
1. 检查 `checkOpenidBinding` API 返回的 `isBound` 字段
2. 检查 `handleWechatLogin` 中的判断逻辑
3. 检查控制台日志中的绑定状态
