# 数据加载显示问题修复说明

## 问题描述
1. 员工账号登录，跳转到员工首页的项目数据默认不会显示，下拉刷新后又正常显示
2. 客户角色登录，跳转到客户首页，项目卡片不会自动显示，下拉以后才会正常显示
3. 客户角色登录，点击进入到我的页面，项目卡片、合同卡片不会自动显示，下拉以后才会正常显示

## 问题原因分析
这是典型的**异步数据加载时序问题**：

1. **Loading状态管理不当**: 页面初始化时，loading状态没有正确设置，导致组件在数据加载完成前就显示了空状态
2. **模板渲染时机**: Vue组件的模板渲染可能在异步数据加载完成之前执行，此时数据为空数组
3. **缺少加载状态提示**: 用户看不到数据正在加载，以为没有数据

## 修复方案

### 1. Dashboard页面修复

#### 问题
- `onMounted`中的数据加载是异步的，但loading状态管理不正确
- 员工和客户的数据加载完成前，组件就显示了空状态

#### 修复
```javascript
// 修复前
onMounted(async () => {
  // ... 其他逻辑
  await loadDashboardData() // loading状态可能在这里没有正确设置
})

// 修复后
onMounted(async () => {
  // ... 其他逻辑
  
  // 确保loading状态正确设置
  loading.value = true
  await loadDashboardData()
})
```

#### 添加加载状态显示
在CustomerDashboard组件中添加项目数据加载状态：
```vue
<!-- 项目数据加载中（已登录客户但项目数据还在加载） -->
<view v-else-if="!isGuestMode && props.loading" class="project-loading">
  <view class="loading-spinner"></view>
  <text>加载项目数据中...</text>
</view>
```

### 2. Profile页面修复

#### 问题
- 项目数据和合同数据都是异步加载，但没有加载状态提示
- 用户看到空白区域，不知道数据正在加载

#### 修复
1. **添加数据加载状态**:
```javascript
const dataLoading = ref(false) // 添加数据加载状态

const loadProjectData = async () => {
  dataLoading.value = true
  try {
    // ... 加载逻辑
  } finally {
    dataLoading.value = false
  }
}
```

2. **修改模板显示逻辑**:
```vue
<!-- 修复前：只有有数据时才显示 -->
<view v-if="shouldShowProjects && projects.length > 0">
  <ProjectCardSwiper ... />
</view>

<!-- 修复后：显示加载状态和空状态 -->
<view v-if="shouldShowProjects">
  <!-- 数据加载中 -->
  <view v-if="dataLoading" class="loading-placeholder">
    <view class="loading-spinner"></view>
    <text>加载项目数据中...</text>
  </view>
  <!-- 项目数据 -->
  <ProjectCardSwiper v-else-if="projects.length > 0" ... />
  <!-- 无项目提示 -->
  <view v-else class="no-projects-tip">
    <text>暂无关联项目</text>
  </view>
</view>
```

3. **确保异步加载**:
```javascript
// 修复前
onMounted(() => {
  if (isLoggedIn.value) {
    loadProjectData() // 没有await
  }
})

// 修复后
onMounted(async () => {
  if (isLoggedIn.value) {
    await loadProjectData() // 确保等待加载完成
  }
})
```

### 3. 添加加载状态样式
为所有加载状态添加统一的样式：
```scss
.loading-placeholder {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  padding: 80rpx 32rpx;
  background: $color-gray-50;
  border-radius: $radius-xl;
  border: 2rpx dashed $color-border;
  
  .loading-spinner {
    width: 60rpx;
    height: 60rpx;
    border: 4rpx solid #f3f3f3;
    border-top: 4rpx solid $color-brand;
    border-radius: 50%;
    animation: spin 1s linear infinite;
    margin-bottom: 24rpx;
  }
  
  text {
    font-size: 26rpx;
    color: $color-text-tertiary;
  }
}
```

## 修复效果

### 修复前
- ❌ 页面初始加载时显示空白
- ❌ 用户不知道数据正在加载
- ❌ 需要手动下拉刷新才能看到数据

### 修复后
- ✅ 页面初始加载时显示加载动画
- ✅ 用户能看到"加载中..."提示
- ✅ 数据加载完成后自动显示
- ✅ 无数据时显示友好提示

## 测试验证
1. **员工登录** → 首页显示加载状态 → 自动显示项目列表
2. **客户登录** → 首页显示加载状态 → 自动显示项目卡片
3. **客户进入个人中心** → 显示加载状态 → 自动显示项目和费用信息
4. **网络较慢时** → 用户能看到加载提示，不会误以为没有数据

## 技术要点
1. **正确的loading状态管理**: 确保在数据加载期间loading为true
2. **异步操作的await**: 确保onMounted中的异步操作正确等待
3. **用户体验优化**: 提供加载状态和空状态的友好提示
4. **模板条件渲染**: 使用v-if/v-else-if正确处理不同状态的显示
