# 个人中心登录引导显示修正说明

## 问题分析

根据调试日志显示，用户状态为：
- `isLoggedIn: false` - 未登录
- `游客模式: true` - 处于游客模式
- `hasWechatOpenid: true` - 有微信openid

但是个人中心页面没有显示登录引导按钮。

## 问题原因

### 原有的显示逻辑问题
```javascript
const shouldShowLoginGuide = computed(() => {
  // 未登录且非游客模式时显示登录引导
  return !isLoggedIn.value && !isGuestMode.value
})
```

根据当前状态：
- `!isLoggedIn.value` = `!false` = `true`
- `!isGuestMode.value` = `!true` = `false`
- 结果：`true && false = false`

所以 `shouldShowLoginGuide` 返回 `false`，不显示登录引导。

### 逻辑错误分析
原逻辑的意图是"只有未登录且非游客模式的用户才显示登录引导"，但这是错误的：
- **游客模式的用户也需要登录引导**
- **所有未登录的用户都应该看到登录引导**

## 修正方案

### 1. 修正显示逻辑
```javascript
const shouldShowLoginGuide = computed(() => {
  // 未登录时显示登录引导（包括游客模式）
  return !isLoggedIn.value
})
```

修正后的逻辑：
- 只要用户未登录，就显示登录引导
- 不论是否处于游客模式

### 2. 完善登录引导内容
```vue
<!-- 未登录用户引导登录 -->
<view v-if="shouldShowLoginGuide" class="login-guide-section">
  <view class="login-guide-card">
    <view class="guide-icon">🔐</view>
    <text class="guide-title">登录后享受更多服务</text>
    <text class="guide-desc">登录后可查看项目进度、费用明细等个人信息</text>
    <view class="guide-btn" @click="handleGoLogin">
      <text>立即登录</text>
    </view>
  </view>
</view>
```

### 3. 增强调试日志
```javascript
console.log('[Profile] shouldShowLoginGuide:', shouldShowLoginGuide.value)
console.log('[Profile] isGuestMode:', isGuestMode.value)
```

## 修正后的显示规则

| 用户状态 | isLoggedIn | isGuestMode | shouldShowLoginGuide | 显示内容 |
|---------|------------|-------------|---------------------|---------|
| 未登录普通用户 | false | false | **true** | 登录引导 |
| 未登录游客用户 | false | true | **true** | 登录引导 |
| 已登录游客用户 | true | false | false | 导入按钮 |
| 已登录正式用户 | true | false | false | 正常功能 |

## 用户体验流程

### 修正前的问题流程
1. 用户进入游客模式
2. 访问个人中心 → **没有登录引导** ❌
3. 用户不知道如何登录

### 修正后的正确流程
1. 用户进入游客模式
2. 访问个人中心 → **显示登录引导** ✅
3. 点击"立即登录" → 跳转登录页
4. 登录成功 → 显示导入按钮或正常功能
