# 绑定函数修复说明

## 问题描述

在实现"导入历史数据"功能时，发现以下问题：

1. **参数传递错误**：原代码直接传递 `code` 给 `bindPhoneToOpenid` 接口，但后端实际需要 `openid` 参数
2. **缺少绑定验证**：没有在绑定前检查账号和微信是否已经绑定
3. **API函数未导入**：`checkOpenidBinding` 和 `openidLogin` 函数未在 profile 页面导入

## 后端接口分析

### 1. 检查绑定状态接口
```java
@PostMapping("/check-openid-binding")
public AjaxResult checkOpenidBinding(@RequestBody CheckOpenidBindingRequest request)
```
- **输入**：`{ code, deviceId }`
- **输出**：`{ openid, isBound, phone?, userInfo? }`
- **功能**：通过微信code获取openid，并检查该openid是否已绑定账号

### 2. 绑定接口
```java
@PostMapping("/bind-phone-to-openid")
public AjaxResult bindPhoneToOpenid(@RequestBody BindPhoneToOpenidRequest request)
```
- **输入**：`{ openid, phone, deviceId }`（注意：需要 openid，不是 code）
- **输出**：`{ token, refreshToken, userInfo }`
- **功能**：将手机号绑定到openid，并返回登录信息

### 3. Openid登录接口
```java
@PostMapping("/openid-login")
public AjaxResult openidLogin(@RequestBody OpenidLoginRequest request)
```
- **输入**：`{ openid, deviceId }`
- **输出**：`{ token, refreshToken, userInfo }`
- **功能**：使用已绑定的openid直接登录

## 后端验证逻辑

后端 `bindPhoneToOpenid` 方法已包含完整的验证逻辑：

1. ✅ 检查手机号是否在系统中注册
2. ✅ 检查账号状态是否正常
3. ✅ 检查该openid是否已绑定其他账号
4. ✅ 检查该手机号是否已绑定其他openid

## 修复方案

### 正确的绑定流程

```javascript
async performPhoneBinding(phone) {
  // 1. 获取微信code
  const wechatCode = uni.getStorageSync('wechatCode')
  
  // 2. 通过code获取openid并检查绑定状态
  const checkResult = await checkOpenidBinding(wechatCode)
  const openid = checkResult.openid
  
  // 3. 如果已绑定，直接登录
  if (checkResult.isBound) {
    const loginResult = await openidLogin({ openid, deviceId })
    // 保存登录信息，刷新页面
    return
  }
  
  // 4. 未绑定，执行绑定操作
  const result = await bindPhoneToOpenid({ openid, phone, deviceId })
  // 保存登录信息，刷新页面
}
```

### 代码修改

#### 1. 添加API导入
```javascript
import { bindPhoneToOpenid, checkOpenidBinding, openidLogin } from '@/api/auth.js'
```

#### 2. 完善 performPhoneBinding 函数
- 先调用 `checkOpenidBinding` 获取 openid
- 检查是否已绑定，已绑定则直接登录
- 未绑定则调用 `bindPhoneToOpenid` 执行绑定
- 处理各种错误场景（账号未注册、已绑定其他账号等）

## 错误处理

### 1. 账号未注册
```
账号 xxx 未在系统中注册。
请联系管理员将您的账号添加到系统中，或使用其他已注册的账号。
```

### 2. 账号已绑定其他微信
```
该账号已绑定其他微信账号，一个账号只能绑定一个微信账号。
```

### 3. 微信已绑定其他账号
```
该微信账号已绑定其他账号，请使用已绑定的账号登录。
```

### 4. 账号格式错误
- 允许重试3次
- 超过3次则提示"账号格式错误次数过多"

## 测试场景

### 场景1：首次绑定（正常流程）
1. 游客模式登录
2. 点击"导入历史数据"
3. 输入已注册的账号
4. 系统检查：openid未绑定，账号未绑定
5. 执行绑定，返回登录信息
6. 清除游客模式，刷新页面显示项目数据

### 场景2：已绑定直接登录
1. 游客模式登录（使用已绑定过的微信）
2. 点击"导入历史数据"

4. 系统检查：openid已绑定
5. 直接使用openid登录
6. 清除游客模式，刷新页面显示项目数据

### 场景3：账号未注册
1. 游客模式登录
2. 点击"导入历史数据"
3. 输入未注册的账号
4. 系统提示：账号未注册
5. 提供"重新输入"和"取消"选项

### 场景4：账号已绑定其他微信

6. 只能点击"我知道了"

4. **用户体验**：已绑定的情况下直接登录，无需重复绑定
5. **游客模式**：绑定成功后要清除游客模式标记
