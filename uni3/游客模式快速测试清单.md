## 关键检查点

### 1. 无限循环检查 ⚠️
**问题：** 登录后一直在登录页和首页之间跳转

**检查：**
```javascript
// 检查 isLoggedIn 函数
import { isLoggedIn, isGuestMode } from '@/utils/permission'
console.log('游客模式:', isGuestMode())
console.log('已登录:', isLoggedIn())
// 游客模式下，isLoggedIn() 应该返回 true
```

### 2. 路由拦截检查 ⚠️
**问题：** 游客模式下无法访问某些页面

**检查：**
- 确认 `isLoggedIn()` 在游客模式下返回 `true`
- 确认 `hasPagePermission()` 在游客模式下返回 `true`

### 3. 首页显示检查 ⚠️
**问题：** 首页显示"请先登录"

**检查：**
```javascript
// 在 dashboard/index.vue 的 onMounted 中
const isGuest = uni.getStorageSync('guestMode') === true
console.log('是否游客:', isGuest)
console.log('用户类型:', userType.value)
// 游客模式下，userType 应该是 'customer'
```

## 快速调试命令

```javascript
// 查看当前状态
console.log('=== 当前状态 ===')
console.log('游客模式:', uni.getStorageSync('guestMode'))
console.log('微信Code:', uni.getStorageSync('wechatCode'))
console.log('Token:', uni.getStorageSync('token'))
console.log('用户信息:', uni.getStorageSync('userInfo'))

// 切换到游客模式
uni.setStorageSync('guestMode', true)
uni.setStorageSync('wechatCode', 'test_code')
uni.removeStorageSync('token')
console.log('已切换到游客模式')

// 切换到正式用户
uni.removeStorageSync('guestMode')
uni.removeStorageSync('wechatCode')
uni.setStorageSync('token', 'test_token')
console.log('已切换到正式用户')

// 完全清除
uni.clearStorageSync()
console.log('已清除所有缓存')
```
