# 游客模式资讯显示优化说明

## 优化目标

让游客模式下的概况页面（dashboard）也能显示资讯信息和banner，不需要登录状态即可浏览公共内容。

## 优化内容

### 1. Dashboard页面逻辑调整

**文件：** `uni3/src/pages/dashboard/index.vue`

**改动：**
```javascript
if (isGuest) {
  // 游客模式，设置为客户类型
  userType.value = 'customer'
  console.log('[Dashboard] 游客模式，显示客户视图')
  // 游客模式下也显示资讯和banner，但不显示项目数据
  projects.value = [] // 空项目列表
  loading.value = false
  return
}
```

**关键点：**
- 游客模式下设置 `userType = 'customer'`
- 设置空项目列表 `projects = []`
- 不加载需要token的项目数据
- 让CustomerDashboard组件正常渲染

### 2. CustomerDashboard组件优化

**文件：** `uni3/src/pages/dashboard/components/CustomerDashboard.vue`

#### 改动1：移除条件渲染
```vue
<!-- 旧代码 -->
<scroll-view v-if="projects.length > 0">
  <!-- 内容 -->
</scroll-view>
<view v-else class="no-project">
  暂无关联项目
</view>

<!-- 新代码 -->
<scroll-view>
  <!-- Banner和资讯始终显示 -->
  <BannerSwiper :banners="bannerList" />
  
  <!-- 项目卡片仅在有项目时显示 -->
  <ProjectCardSwiper v-if="projects.length > 0" />
  
  <!-- 无项目提示 -->
  <view v-else class="no-project-tip">
    <!-- 友好提示 -->
  </view>
  
  <!-- 资讯始终显示 -->
  <NewsTab />
</scroll-view>
```

#### 改动2：添加游客模式判断
```javascript
// 游客模式判断
const isGuestMode = computed(() => uni.getStorageSync('guestMode') === true)
```

#### 改动3：优化无项目提示
```vue
<view class="no-project-tip">
  <view class="tip-icon">📋</view>
  <text class="tip-text">
    {{ isGuestMode ? '导入历史数据后可查看您的项目' : '暂无关联项目' }}
  </text>
  <view v-if="isGuestMode" class="tip-action" @click="goToProfile">
    <text>去导入数据</text>
  </view>
</view>
```

#### 改动4：添加跳转逻辑
```javascript
// 跳转到个人中心导入数据
const goToProfile = () => {
  uni.switchTab({ url: '/pages/profile/index' })
}
```

## API调用说明

### 游客模式下的API调用

**不调用的API：**
- ❌ `getCustomerDashboard()` - 需要token，获取项目数据
- ❌ `getStaffDashboard()` - 需要token，获取员工项目

**正常调用的API：**
- ✅ `getBannerNews()` - 公共接口，获取banner
- ✅ `getNewsList()` - 公共接口，获取资讯列表

### 后端接口要求

**Banner接口：** `/app/news/banner`
- 不需要token验证
- 返回所有公开的banner数据

**资讯列表接口：** `/app/news/list`
- 不需要token验证
- 返回公开的资讯数据
- 支持分页和分类
