# 登录逻辑调整完成总结

## 调整概述

根据微信小程序审核规范，我们重新设计了登录逻辑，采用"游客模式 + 导入历史数据"的策略，完全符合"用完即走"的设计理念。

## 核心改动

### 1. 登录页面（index-new.vue）

**改动内容：**
- 微信登录直接进入首页，不进行任何验证
- 保存微信code用于后续导入数据
- 设置游客模式标记
- 简化了静默登录逻辑

**关键代码：**
```javascript
const handleWechatLogin = async () => {
  // 获取微信code
  const loginRes = await uni.login({ provider: 'weixin' })
  
  // 保存code
  uni.setStorageSync('wechatCode', loginRes.code)
  
  // 设置游客模式
  uni.setStorageSync('guestMode', true)
  
  // 直接跳转首页
  uni.reLaunch({ url: '/pages/dashboard/index' })
}
```

### 2. 个人中心（profile/index.vue）

**新增功能：**
- 添加"导入历史数据"按钮（仅游客模式显示）
- 集成手机号输入和绑定流程
- 导入成功后自动切换为正式用户

**关键代码：**
```vue
<!-- 导入历史数据按钮 -->
<view v-if="isGuestMode" class="action-btn import-data-btn" @click="handleImportData">
  <text>导入历史数据</text>
```

### 3. 权限控制（utils/permission.js）

**改动内容：**

```javascript
// 保存code用于后续导入
```

```javascript
// 导入成功后清除游客模式
```

### 4. 退出登录
```javascript

userStore.logout()
```

## 后端需要配合的改动

### 1. 绑定接口调整

**接口路径：** `/app/auth/bind-phone-to-openid`

**请求参数变化：**
```javascript
// 旧参数
{
  openid: 'xxx',
  phone: '13800138000',
  deviceId: 'xxx'
}

// 新参数
{
  code: 'xxx',  // 微信登录code
  phone: '13800138000',
  deviceId: 'xxx'
}
```

**后端处理流程：**
1. 接收code参数
2. 调用微信API通过code获取openid
3. 验证手机号是否在系统中注册
4. 检查openid是否已绑定其他账号
5. 绑定openid到用户账号
6. 生成token
7. 返回完整的用户信息和token

**响应数据：**
```json
{
  "code": 200,
  "data": {
    "accessToken": "xxx",
    "refreshToken": "xxx",
    "userType": "customer",
    "userInfo": {
      "id": "1",
      "name": "张三",
      "phone": "13800138000",
      "avatar": ""
    },
    "projects": [...]
  }
}
```

### 2. 错误处理

**手机号未注册：**
```json
{
  "code": 400,
  "msg": "手机号未在系统中注册"
}
```

**openid已绑定其他账号：**
```json
{
  "code": 400,
  "msg": "该微信账号已绑定其他手机号"
}
```

**微信code无效或过期：**
```json
{
  "code": 400,
  "msg": "微信登录信息已过期，请重新登录"
}
```
