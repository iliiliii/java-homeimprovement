# 菜单权限过滤功能说明

## 修改内容

在 `vue3/src/store/modules/permission.js` 中添加了菜单过滤功能，实现非 admin 账户隐藏系统管理相关菜单。

## 功能说明

### 隐藏的菜单
对于非 admin 角色的用户，以下三个菜单将被隐藏：
- 系统监控 (`/monitor`)
- 系统工具 (`/tool`)
- 系统管理 (`/system`)

### 实现逻辑

1. **新增函数 `filterSystemMenus`**
   - 从 userStore 获取当前用户的角色信息
   - 如果用户角色包含 `admin`，则不进行过滤，显示所有菜单
   - 如果用户角色不包含 `admin`，则过滤掉路径为 `/monitor`、`/tool`、`/system` 的菜单

2. **修改 `generateRoutes` 方法**
   - 在设置侧边栏路由之前，调用 `filterSystemMenus` 函数过滤菜单
   - 只对侧边栏菜单进行过滤，不影响路由的实际访问权限

3. **导入依赖**
   - 新增导入 `useUserStore`，用于获取用户角色信息

## 使用场景

- **admin 用户**：可以看到所有菜单，包括系统监控、系统工具、系统管理
- **非 admin 用户**：只能看到业务相关菜单，系统管理相关的三个菜单被隐藏

## 注意事项

1. 此修改只是在前端隐藏菜单，不影响后端权限控制
2. 如果需要完全禁止访问，还需要在后端进行权限验证
3. 菜单过滤基于用户角色中是否包含 `admin` 字符串
4. 如果需要修改隐藏的菜单列表，可以在 `filterSystemMenus` 函数中修改 `hiddenPaths` 数组

## 测试建议

1. 使用 admin 账户登录，验证所有菜单是否正常显示
2. 使用非 admin 账户登录，验证系统监控、系统工具、系统管理三个菜单是否被隐藏
3. 验证其他业务菜单是否正常显示和访问
