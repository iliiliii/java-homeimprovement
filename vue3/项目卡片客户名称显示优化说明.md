# 项目卡片客户名称显示优化说明

## 优化目标

在 `vue3/src/views/evs/projects/card.vue` 组件中，项目卡片应该显示**客户名称**而不是**客户ID**。

---

## 问题分析

### 当前显示效果

**问题**：卡片中显示的是客户ID（如：`48374b34460847d4b8c4616becbdfaef`）

**原因**：
1. API 调用没有请求客户信息
2. 或者后端返回的数据中 `customer` 对象为 null

---

## 优化方案

### 1. 确保 API 返回客户信息

**文件**：`vue3/src/api/evs/projects.js`

**已修改**：
```javascript
// 通过项目成员关联查询项目列表（支持管理员权限筛选，包含进度统计和客户信息）
export function listProjectsWithMembers(query) {
  return request({
    url: '/evs/projects/list',
    method: 'get',
    params: {
      ...query,
      includeScheduleInfo: true,  // 获取进度统计信息
      includeCustomer: true        // ✅ 获取客户信息
    }
  })
}
```

---

### 2. 优化客户名称显示逻辑

**文件**：`vue3/src/views/evs/projects/card.vue`

#### 修改前

```javascript
function getCustomerName(project) {
  if (project.customer && project.customer.name) {
    return project.customer.name
  }
  return project.customerId || '未关联客户'  // ❌ 显示客户ID
}
```

**问题**：当 `customer` 对象为 null 时，会显示客户ID

---

#### 修改后

```javascript
function getCustomerName(project) {
  // 优先从关联的客户对象中获取名称
  if (project.customer && project.customer.name) {
    return project.customer.name  // ✅ 显示客户名称
  }
  
  // 如果有 customerId 但没有 customer 对象，显示提示信息
  if (project.customerId) {
    console.warn('[项目列表] 项目有 customerId 但缺少 customer 对象:', {
      projectId: project.id,
      projectName: project.name,
      customerId: project.customerId,
      customer: project.customer
    })
    return `客户ID: ${project.customerId}`  // 临时显示，便于调试
  }
  
  // 完全没有客户信息
  return '未关联客户'
}
```

**改进点**：
1. 优先显示客户名称
2. 如果缺少客户对象，输出警告日志便于调试
3. 临时显示客户ID，方便排查问题

```
1. 前端调用 API
   ↓
   listProjectsWithMembers({
     includeScheduleInfo: true,
     includeCustomer: true
   })

2. 后端处理
   ↓
   Controller: 接收参数
   ↓
   Service: selectProjectsListWithScheduleInfo(projects, true)
   ↓
   Mapper: selectProjectsWithCustomer(query)
   ↓
   SQL: LEFT JOIN customers 表

3. 返回数据
   ↓
   {
     id: "proj_001",
     name: "飞虹展厅",

       phone: "13800138000"
     }
   }

4. 前端显示
   ↓
   getCustomerName(project)
   ↓
   返回: "广州飞虹微电子有限公司"  ✅
```

## 卡片模板代码

**文件**：`vue3/src/views/evs/projects/card.vue`

```vue
<!-- 客户信息 -->
<div style="display: flex; align-items: center; margin-bottom: 8px; font-size: 13px; color: #606266;">
  <el-icon style="margin-right: 6px;"><User /></el-icon>
  <span>客户：</span>
  <el-link
    v-if="project.customerId && getCustomerName(project) !== '未关联客户'"
    type="primary"
    :underline="false"
    @click="showCustomerInfo(project.customerId)"
    style="margin-left: 4px; font-size: 13px;"
  >
    {{ getCustomerName(project) }}  <!-- ✅ 显示客户名称 -->
  </el-link>
  <span v-else style="margin-left: 4px;">{{ getCustomerName(project) }}</span>
</div>
```

**显示逻辑**：
1. 如果有客户信息，显示为可点击的链接（蓝色）
2. 点击链接可以查看客户详情
3. 如果没有客户信息，显示普通文本

## 可能的问题

### 问题 1：customer 对象为 null

**原因**：
- 后端修改没有生效（未重启）
- 数据库中没有对应的客户数据
- `projects.customer_id` 字段为空或错误

**解决方法**：
1. 重启后端服务
2. 检查数据库数据
3. 确保项目正确关联客户

---

### 问题 2：依然显示客户ID

**原因**：
- 浏览器缓存了旧数据
- API 请求参数没有正确传递

**解决方法**：
1. 清除浏览器缓存
2. 硬刷新页面（Ctrl + Shift + R）
3. 检查 Network 请求参数

---

### 问题 3：点击客户名称没有反应

**原因**：
- `CustomerInfoDialog` 组件未正确实现
- `customerId` 为空

**解决方法**：
1. 检查 `CustomerInfoDialog` 组件
2. 确保 `customerId` 正确传递
